# 3D-ITC Website

Company website for **3D-ITC: 3D Information Technology Consultancy**. It covers IT consultation, websites, web apps, VPNs, virtual machines and in-house cloud infrastructure.

It's a single static page (`index.html`) with no build step. Open it in a browser, or host it with GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**.

## Files
- `index.html`: the full site (HTML, CSS and JS in one file; fonts load from Google Fonts)
- `logo.png`: the original logo
- `favicon.svg`: the logo mark, used as the browser-tab icon
